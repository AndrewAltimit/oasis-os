OASIS Browser Engine Reaches 1.0 Milestone

By Jane Developer | February 23, 2026 | 5 min read

The open-source OASIS browser engine, originally designed for the PlayStation Portable, has reached its 1.0 release after years of development. The engine supports HTML5, CSS, and even the Gemini protocol.

What makes OASIS unique is its extreme portability. The rendering engine runs on hardware as constrained as the PSP (333MHz MIPS, 32MB RAM) while also scaling to modern desktop platforms and Unreal Engine 5.

"We wanted to prove that a browser doesn't need gigabytes of RAM"

The project began as a homebrew shell for the PSP in 2006, originally written in C. The current version is a complete rewrite in Rust, taking advantage of the language's memory safety guarantees.

The browser supports block, inline, table, and flexbox layout, plus CSS custom properties, positioned elements, and float-based designs.

Key features of the 1.0 release include:

  • Full HTML5 parsing with 50+ element types
  • CSS cascade with specificity and inheritance
  • Block, inline, table, and flexbox layout
  • Image support (BMP, PNG, JPEG)
  • Gemini protocol support
  • Reader mode for article extraction

The team plans to continue improving text rendering quality, adding extended character set support, and implementing CSS gradients in upcoming releases.
