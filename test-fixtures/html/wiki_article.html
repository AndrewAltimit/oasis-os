Rust is a general-purpose programming language emphasizing performance, type safety, and concurrency. It enforces memory safety without a garbage collector. Rust was originally designed by Graydon Hoare at Mozilla Research.

History

Rust grew out of a personal project begun in 2006 by Mozilla Research employee Graydon Hoare. Mozilla began sponsoring the project in 2009. The first stable release, Rust 1.0, was announced on May 15, 2015.

In 2021, the Rust Foundation was established as an independent non-profit organization to steward the language. Founding members included AWS, Google, Huawei, Microsoft, and Mozilla.

Features

Memory safety

Rust's ownership system ensures memory safety at compile time without needing a garbage collector. Each value has a single owner, and the compiler checks that references (&T and &mut T) follow strict borrowing rules.

Concurrency

The type system prevents data races at compile time. Traits like Send and Sync control which types can be shared across threads.

Syntax and semantics

A simple "Hello, World!" program in Rust:

fn main() {
    println!("Hello, World!");
}

Rust uses pattern matching extensively:

match value {
    1 => println!("one"),
    2 | 3 => println!("two or three"),
    _ => println!("other"),
}
